# 动作要领提示音清单（第二批 83 个动作）

> 来源：《全身训练动作教学手册（83个动作）》+ 83 段录屏要点。
> 用途：语音提示代码的素材表。每条动作给出「入场准备」「周期要领」「错误纠错」三类提示音。

## 一、通用要领（所有动作共享，按部位选用）

**下肢**：膝盖沿脚尖方向，不要内扣；收紧核心，腰不要塌；下放慢一点，两到三秒控制回位；发力时吐气，还原时吸气
**臀部**：用臀部发力，不要用腰代偿；收紧核心，腰背保持稳定；顶端停一下，感受臀部收缩；下放慢一点，保持张力
**肩部**：沉肩，肩膀远离耳朵；用大臂发力，不要用手臂甩；核心收紧，身体不要晃动；发力时吐气，还原时吸气
**手臂**：大臂固定不动，只有肘在动；沉肩，不要耸肩借力；下放慢一点，保持张力；发力时吐气，还原时吸气
**核心**：收紧核心，腰不要塌；用腹部发力，不要用腰；下放不要完全放松，保持张力；呼吸均匀，不要憋气
**小腿**：踮到最高点停一下；下放到最低，做全幅度；膝盖保持稳定，不要借力；发力时吐气，还原时吸气
**前臂**：前臂固定不动，只动手腕；幅度做满，顶端停一下；下放控制住，不要甩；发力时吐气
**有氧**：保持均匀呼吸，不要憋气；心率控制在减脂区间；上身直立，不要一直扶把手；感觉太喘就降一点速度
**胸**：沉肩，肩胛后缩贴稳；大臂与身体约六十度；下放慢一点，控制离心；发力时吐气，还原时吸气
**背部**：先沉肩，再动手臂；用背部发力，不要用手拉；收紧核心，腰背稳定；下放慢一点，保持张力
